# logistic-regression-Diabetes-prediction-
AI 100 Logistic Regression project using the PIMA Indians Diabetes dataset to predict diabetes outcomes.
The notebook:
Loads and explores the dataset
Select features & target
Splits data into train & test
Trains a logistic regression model
Makes prediction
Evaluates the model using accuracy, a confusion matrix and a classification report.
Calculates prediction probabilities
Tests the model on a hypothetical patient
Displays model coefficients.
